Historical record of company names for Hong Kong registered companies. Each row is one distinct name in one language (English, Chinese, or Other) for one company, with the registry's effective date range where available. Exactly one name per company and language is flagged as the current name. Reconciled across legacy Companies Registry data, the modern ICRIS API, company profiles, and the crhkall database. Useful for identifying predecessor companies and tracing corporate history.

cr_number String Company Registration Number (may be empty for modern-only records) — —
company_name String The company name (current or former) for this language. Where the Companies Registry stored the name wrapped in enclosing parentheses — a marker it applies to the secondary-language name on records from roughly 1988-2005, not part of the registered name — those outer brackets are removed upstream; parentheses that belong to the name itself are kept. Removing them merges entries the Registry had recorded as two names when they are one, so a name held continuously across such a record reads as one period rather than two — —
name_language String Name language: English, Chinese, or Other (replaces the legacy E/C/I/O/T name_type codes) — —
name_sequence Int32 Source-provided ordinal of this name within the company's history for this language (0-based; lower = earlier) — —
is_current Bool True if this is the company's current name for this language — exactly one per (company, language) — —
effective_from Nullable(String) Effective-from date for this name, as an ISO 'YYYY-MM-DD' string. Normally the registry's own date; for a never-renamed company's current name with no registry date it is backfilled with the incorporation date — see effective_from_is_estimated. The oldest backfilled dates reach 1878, older than any ClickHouse date type can hold, so this is text rather than a date type. Null when neither source provides a date — —
effective_from_is_estimated Bool True when effective_from is the inferred incorporation date (never-renamed founding name) rather than a registry-provided date — treat it as approximate. False when effective_from is registry-sourced or null — —
effective_to Nullable(String) Registry effective-to date for this name, as an ISO 'YYYY-MM-DD' string (null = current name) — —
updated_at Nullable(DateTime64(3, 'UTC')) Timestamp when record was last observed — —
