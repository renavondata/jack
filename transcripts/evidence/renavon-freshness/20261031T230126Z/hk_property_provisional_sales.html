Provisional (pending-registration) Hong Kong property sales from Centaline — sales agreed but not yet registered with the Land Registry. A leading market-velocity / sales-in-progress signal: these typically register weeks later and reappear in hk_property_transactions with a memorial. Kept separate from registered sales so the two are never double-counted.

building_code Nullable(String) Centaline building code of the building the provisional sale is in — links to hk_property_buildings (estate/building names, geo, district). Placed from the listing's own Centaline building link, else from the building its unit belongs to, and only where that building sits inside the phase or estate the listing is coded to. NULL (under 0.1% of rows) when no building can be placed without contradicting that phase or estate; phase_code and estate_code still locate those rows — —
building_code_source Nullable(String) How building_code was placed: bldggrp = the listing's own Centaline building link (its cblgcode); unit = the building the listing's unit belongs to; unit_code_prefix = the first 10 characters of a 14-character unit code; sole_phase_member = the only building in the listing's phase; typecode = the listing was coded to a building directly. NULL when building_code is NULL — —
