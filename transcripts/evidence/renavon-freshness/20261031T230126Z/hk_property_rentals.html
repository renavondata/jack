Hong Kong residential rental records from Centaline (Centadata). One row per rental record: date, monthly rent, saleable and gross floor areas, rent per square foot on both bases, plus bedroom count and aspect. The rental counterpart to hk_property_transactions (sales). Rentals never register with the Land Registry, so this is a recent series rather than a deep historical archive.

rental_id String Centaline listing reference — unique identifier for the rental listing (rentals do not register, so there is no Land Registry memorial) — —
unit_code Nullable(String) Centaline unit code — links to hk_property_units — —
building_code Nullable(String) Centaline building code of the building the rental listing is in — links to hk_property_buildings (estate/building names, geo, district). Placed from the listing's own Centaline building link, else from the building its unit belongs to, and only where that building sits inside the phase or estate the listing is coded to. NULL (about 2% of rows) when no building can be placed without contradicting that phase or estate; phase_code and estate_code still locate those rows — —
building_code_source Nullable(String) How building_code was placed: bldggrp = the listing's own Centaline building link (its cblgcode); unit = the building the listing's unit belongs to; unit_code_prefix = the first 10 characters of a 14-character unit code; sole_phase_member = the only building in the listing's phase; typecode = the listing was coded to a building directly. NULL when building_code is NULL — —
phase_code Nullable(String) Centaline phase code — the construction/launch tranche of a development the rental listing sits in; links to hk_property_phases. The placed building's phase, else the phase the listing is coded to. NULL when neither is known — —
estate_code Nullable(String) Centaline estate code — the named multi-phase development the rental listing sits in; links to hk_property_estates. NULL for standalone developments that belong to no estate, and when the estate is unknown — —
rent_date Date Listing date in the Hong Kong calendar (YYYY-MM-DD) — —

rent_per_saleable_sqft Nullable(Float64) Monthly rent divided by saleable area (HK$/sqft); null when saleable area is unknown — —
rent_per_gross_sqft Nullable(Float64) Monthly rent divided by gross area (HK$/sqft); null when gross area is unknown — —
block Nullable(String) Block/tower label (English) — —

unit_type Nullable(String) Unit type from the centanet feed (e.g. AP = apartment, HS = house, LR/MR/HR = low/mid/high-rise) — —
